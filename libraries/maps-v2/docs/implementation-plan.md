## Этап 2 — первая картинка

Цель: `zoom-bands` показывает сушу/воду/парк из фикстуры,
`data-state=ready`, readout'ы фактические.

**2.1 `maps2-tile`: формат v0.** `TileBytes` (владение буфером),
`TileView` (вью без копий: заголовок → таблица секций `(class, offset,
len)` → фичи с дельта-varint-zigzag вершинами в `TileCoord`).
`TileBuilder` — для фикстур и будущего пайплайна.
Тесты: round-trip builder→bytes→view покомпонентно; доступ к секции O(1)
без сканирования; битые байты → `Err`, не паника; varint-кодек на
граничных значениях (0, 1, −1, 65535).

**2.2 `maps2-fixtures`: синтетический мир.** Генератор пакета «Илинг»:
полигон суши, лента воды (изгибы как у Темзы), парк, сетка улиц — на
уровнях z0–z16 с полосами (в z8 нет зданий и улиц). Детерминирован:
тест сверяет хэш байтов (golden), смена формата — осознанная смена хэша.

**2.3 `maps2-style`: классы и стиль.** Enum классов (7 дорог + land /
water / park / building + POI + подписи), таблица полос входа, палитра
«тихий холст», рампы ширин по зуму (`width(class, zoom)` — кусочно-
линейная интерполяция).
Тесты: `band(class)`, интерполяция рампы (середина, края, вне диапазона).

**2.4 `maps2-render`: заливки.** Триангуляция полигонов при сборке
бакета (ear clipping; дыры — позже, у фикстур их нет), вершинные буферы,
проход fill по классам. GL-контекст — тонкая обёртка WebGL2.
Тесты (native, без GL): площадь триангуляции = площади полигона;
число вершин бакета; порядок классов в списке проходов.

**2.5 `maps2-web`: обвязка.** `Map::new(canvas_id, fixture_url)`,
`set_zoom(f64)`, `set_centre(lon, lat)`, `debug() -> JsValue` (полоса,
уровень тайлов, резидентные классы, счётчики). Скрипт `build:wasm` в
лабе (wasm-pack, как в map-demo). Граница wasm↔JS — вью, не копия.

**2.6 Лаба: подключение `zoom-bands`.** Карточка грузит wasm, создаёт
Map, слайдер → `set_zoom`, readout'ы из `debug()`; `data-state` →
`ready`. Верификация: DOM-ассерты + скриншот в отчёт.

## Этап 3 — заморозка формата и резидентность

Цель: шесть тогл-карточек и `globe-transition` зелёные; формат v1
заморожен; первые e2e.

**3.1 Резидентность с выселением.** `select_tiles(camera) -> Vec<TileId>`
(покрытие вьюпорта уровнем `floor(zoom)`, кламп к source zoom);
выселение тайлов чужого уровня/полосы; overzoom — родитель с
масштабом в шейдере.
Тесты: тайл z16 не резидентен при камере z6 (баг v1 — регрессионный
тест); overzoom за source zoom; гистерезис на границе уровня.

**3.2 Override полосы и рампы состава.** `set_band_override(band)`
(None = по зуму); альфа-рампа классов ±0.25 зума вокруг границы, с
гистерезисом; режим instant/animated.
Тесты: override при неподвижной камере меняет состав; рампа монотонна;
вне интервала — ровно 0 или 1.

**3.3 Тогл-карточки + `globe-transition`.** Подключить шесть тоглов
(`set_band_override`) и глобусную карточку (readout globeness, тогл
форм). Поднять Playwright в лабе: конфиг, e2e по прямым ссылкам,
DOM-ассерты и инварианты `debug()`.

**3.4 Заморозка.** ✅ Версия формата v1, байтовая раскладка в
[`tile-format.md`](tile-format.md); в фичу добавлены `rank` и `name`
(вход отбора и подписей), заведены растровые секции (`class ≥ 0xFF00`,
высоты `0xFF00`) — чтобы этапы 5 и 7 не ломали формат. Изменение формата
отныне = смена версии в заголовке + миграция фикстур.

## Этап 4 — дороги (параллелен 5–7 после этапа 3)

Цель: `roads-micro` зелёная с golden-скриншотом.

**4.1 Line bucket.** Вершина `{pos: i16×2, normal: i8×2, linesofar:
u16}` (8 байт); стыки при сборке: митра при `1/cos(θ/2) ≤ 2`, дальше
бевел; концы butt/round.
Тесты: число вершин на стык каждого типа; длина митры на 90° = √2;
угол 15° → бевел; `linesofar` монотонен.

**4.2 Line shader + казинг.** Разворот ленты в вершинном шейдере
(`normal · width_px`), ширина — юниформ из рампы стиля; AA smoothstep
по varying; два прохода (казинг шире на 2px, темнее; затем заливка);
порядок по рангу класса.
Верификация: readPixels — казинг темнее заливки, центр ленты — цвет
заливки.

**4.3 Фикстура патологий + карточка.** `maps2-fixtures`: сцена — острый
угол <15°, Y-развязка, круг, дублёр, мост через улицу. Ручки карточки →
стиль-параметры. Golden-скриншот, эталон в коммит, глаза.

**4.4 Мосты и тоннели.** Проход по флагу: мост после всех наземных,
тоннель — приглушённый пунктир казинга. Обновить фикстуру и эталон.

## Этап 5 — подписи и отбор

Цель: `type-specimen`, `labels-collision`, `poi-density`,
`viewport-stability`, затем `labels-line`, `labels-poi`.

**5.1 SDF-атлас.** ✅ Крейт `maps2-text`, офлайн-генератор `gen-atlas`
(атлас PNG + метрики JSON), латиница + цифры + пунктуация, 75 глифов.
**Шрифт не Noto Sans**: взят собственный штриховой скелет в `font.rs`,
обведённый в поле. Причина — детерминизм: атлас строится в процессе и
обязан быть байт-в-байт одинаков на любой машине, иначе всякий golden
ниже по течению зависит от установленных в системе шрифтов. Настоящая
гарнитура меняется заменой одного файла — выше `Atlas` разницы нет.
Шейпинг и юникод остаются записанным долгом.

**5.2 Текстовый проход.** ✅ Квады глифов в экранных координатах, SDF в
фрагментном (резкость на любом размере), halo шириной в em. Текст не в
меше мира: раскладка идёт после проекции, от экранного якоря. →
`type-specimen`, golden работает дважды — до и после bearing 37° /
tilt 55°.

**5.3 Коллизии и ранг.** ✅ Кандидаты из тайлов (дедуп по id через границы),
сортировка по `(rank, id)` — id ради детерминизма; экранная сетка
64 px; жадное размещение. `debug()`: placed и rejected с причинами,
боксы, доля занятой площади экрана.
Тесты-инварианты (не «X виден на z14»!): боксы не пересекаются;
детерминизм кадра; сдвиг ≤20 px → переразмещено <10%; ранги размещённых
не хуже отвергнутых конкурентов. → `labels-collision`.

**5.4 Бюджет экрана.** ✅ Ползунок бюджета занятости в `poi-density`
(тысяча синтетических POI), отсечение по бюджету после ранга: кадр
перестаёт выбирать, а не пропускает крупных ради мелких — иначе на
экране оказалось бы что-то менее важное, чем оставленное за бортом.
→ `poi-density`, `viewport-stability`.

**5.5 Текст вдоль линии.** Размещение по `linesofar` с повтором ~400 px,
переворот против вверх-ногами. → `labels-line`.

**5.6 POI: иконка + текст.** Атлас иконок (несколько kind'ов), связка
«иконка обязательна, текст опционален» в коллизиях. → `labels-poi`.

## Этап 6 — ввод

Цель: `input-flat` зелёная.

**6.1 Контроллер.** DOM-события → `CameraPatch`: drag=pan (пиксели →
дельта центра через обратную проекцию), wheel и pinch=zoom к курсору
(точка под курсором неподвижна: решается относительно centre), dblclick
= +1 с анимацией, стрелки/±.
Тесты (Rust, чистая математика): zoom-к-курсору держит точку; pan на
N px сдвигает центр ровно на N px обратной проекции.

**6.2 Инерция и подключение.** Экспоненциальное затухание после
отпускания; лог событий карточки уже есть — добавить readout камеры из
`debug()`; e2e шлёт wheel/drag и сверяет числа.

## Этап 7 — рельеф

Цель: `terrain-shade`, `globe-relief` зелёные с golden.

**7.1 Тайлы высот в формате.** Растровая секция 256×256 `u16`;
фикстура — синтетический хребет (шум + конус).
**7.2 Hillshade.** Нормаль из градиента в фрагментном шейдере, свет
северо-запад, гипсометрическая тонировка из стиля, ползунок
выразительности. → `terrain-shade`.
**7.3 Глобус.** Вершинное смещение сферы `r = R(1 + h·k·g)`, k≈40,
гаснет с globeness. → `globe-relief`.

## Этап 8 — пайплайн `pipelines/maps-v2-ingest` (после 3.4)

Цель: реальный Лондон + мир для глобуса; `roads-real`.

**8.1 Каркас и чтение OSM.** Крейт с клиппи-лимитами v2; osm.pbf →
наши классы (маппинг тегов задокументирован).
**8.2 Генерализация.** Дуглас—Пекер с допуском уровня; коллапс
city→point; ранги head/tail (population, road class, POI kind).
**8.3 Нарезка.** Формат v1, гейт Тёпфера (перегруз = ошибка сборки),
манифест пакета с версиями.
**8.4 Высоты.** Copernicus GLO-30 → пирамида для Лондона; GEBCO для
глобусных уровней (вода — батиметрия).
**8.5 Подключение.** Пакет Лондона в лабу (`roads-real`), мир z0–z5 для
глобуса; синтетические фикстуры остаются для карточек-патологий.
